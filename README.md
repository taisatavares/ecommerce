# 🛒 Dashboard de Avaliação de E-commerce

Este projeto foi desenvolvido no Power BI com foco na análise das avaliações recebidas por um e-commerce. A proposta foi entender melhor a experiência dos clientes com base em seus feedbacks, identificando padrões de satisfação e pontos de melhoria.

## 📌 Objetivos do projeto

- Avaliar a satisfação geral dos clientes
- Analisar as avaliações por tipo de produto
- Identificar fatores que influenciam avaliações negativas
- Visualizar a reputação da loja ao longo do tempo
- Apoiar a tomada de decisão para melhoria da experiência do usuário

## 📊 Métricas e insights apresentados

- Maiores compras mensais
- Compras por estado civil
- Categoria de produtos mais vendidos
- Média de idade
- Ticket médio
- Quantidade de avaliações por cliente
